# 男鬼剑士技能与控制器证据矩阵

2026-10-18 当前整合：本轮源核对和未闭合调用见 `reports/skill-chain-rework/README.md`，控制器回归见该目录 `tests.json`。新增参考是用户说明的86版本，EXE/PVF与本地1031不同；创建锚点、触发关联和运动公式即使采用跨版本观察，也仍标为重建。`EffectPlan` 读取当前源 OBJ/ALS 的视觉组成并保留 offset/时间/实例；视觉附层不另算伤害。

本轮补全地裂刀光及源 `normalwavefire.ani` 主波、裂波上挑/下斩/尘及与三次实际脉冲同步的普通混合层、银落落地地波/尘/扩散闪光、同轨迹的血十字普通/加色层。地裂325ms单次主波按身体frame4释放；十字身体frame7释放，锚点 `(85,0,82)` 为跨版本观察支持的重建，速度400/停止280ms来自当前源PTL。独立效果使用自身源攻击框，取消了旧中心距离预筛选；血十字开始和末尾的空白帧没有伤害。附着层在人物每tick移动完成后对齐。

银落保存本次技能峰值高度，以50为当前明确重建的门槛；只有足够高度才生成落地冲击组合，着地均恢复移动。崩山ready400ms后进入第二身体动作，在frame4（600ms）落地；源距离50..200/高度50..120按按住0..200ms映射，水平smoothstep/垂直抛物线仍非原生运动公式。默认 `bloodyvigorous` 等级0，不产生冲击波；只有明确拥有源被动63 `skill/swordman/bloodyvigorous.skl` 才启用前后四层波。基础十字不附赠狂战士追击，基础月光不附赠满月第三刀。下表中的“冲击层”均须按这些资格理解。

最新统一构建的技能专项8项通过，包含双向血十字锚点/去重/源空白帧、地裂release/reach、银落解锁、裂波三次普通层、崩山资格/按住距离及附着同步。诊断靶、真实窗口采样和正常窗口输入分别记录在本轮最终报告，不能由核心断言推定原版视觉/平衡一致。

内容权威为原 PC/PVF。`reports/source-evidence/manifest.json` 保存 74 份鬼剑士 REP、19 份主动/被动 SKL、六张 MAP、CHR 与空白 TIL，共 101 份原始解密文件及有序字段/token/hash；当前导出全部与只读研究库哈希匹配。REP 的时间、按键枚举仍未验证，当前没有原 REP 回放功能。

补充交叉参考：`../dnf参考项目/Sys/主角色类/主角_男鬼剑士.lua` 的 2098–2101 行在发动崩山击时显式开启霸体，1097 行清除；这提供了 Lua 实现的行为线索，仍不能直接定义原 PC ANI damageType=1 的枚举。rednf 的 damageType=0/1 是物理/魔法伤害类别，与 ANI 受击保护字段不是同一语义，不能混用。

等级消耗边界：当前 MP 使用 SKL `[consume MP]` 的首项，未实现 min/max 区间随技能等级增长的解释；技能测试面板改等级会改变 level info 伤害参数，但 MP 仍为基础值。正常流程通过属于此 demo 消耗规则，不能当作原版高等级消耗/平衡验证。冷却读取首项，当前这批技能源冷却区间两端相同。
