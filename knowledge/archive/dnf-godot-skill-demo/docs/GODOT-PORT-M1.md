# Godot 移植 M1：UI 与战斗体验切片

状态：实施中，尚未编译或验收。2026-11-02。

本轮按用户授权迁移现有 C++ 功能；完成一个可体验版本后提供反馈清单并暂停。现有 V3.1 预览器和历史候选保持原样。

## 实施边界

- 使用已验证 Mage457 的固定 C++ 源头文件与静态库，隔离未验证的 459 改动。
- Godot 原生 Control/Input/CanvasItem/AudioStreamPlayer 承担界面、输入、画面和音频；PVF 的毫秒时钟、命中规则、装备和交易继续由稳定核心承担。
- 本地进程桥接为本轮离线可构建接口；输入命令与只读绘制快照分离。它不是完整 GDExtension，也不声称填补全部技能原生调用者。
- 读取 Script.pvf 与 ImagePacks2，不改客户端文件；默认从独立程序所在目录定位客户端，开发入口显式指定来源。
- 缓存、日志、进度与独立存档均在 D 盘项目目录，禁止覆盖原 DNF.exe、正常存档或历史候选。

## 本轮确认目标

真实核心角色移动、普攻和已完成技能、基础怪物命中反应；Godot 界面操作及 NPC/商店/装备等可复用业务接口；来源定位和加载反馈。实际覆盖以最终运行报告为准，未实现功能逐项列出。

## 交付门

串行构建、脚本解析、真实核心集成及打包验证后，创建独立 checkpoint，包含源码、编译产物、清单、进度与用户反馈项目。随后停止后续迁移，等待用户确认。
