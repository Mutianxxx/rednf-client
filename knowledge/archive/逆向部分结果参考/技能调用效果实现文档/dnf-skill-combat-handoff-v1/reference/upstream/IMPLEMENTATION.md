# 实现与证据映射

版本 `battle-reconstruction-v1`，源码入口 `src/main.cpp`；原始资源读取 `src/resources.cpp`；内容生成 `tools/prepare.py`。本文件记录已实现行为及推导，不把预览策略写成原客户端事实。

## 输入来源

- 主源为 `reverse_lab/v2/reports/new-client-pvf-snapshot`，客户端 EXE SHA256 `1f8244d3f7309bbe2fde4299e1863a894f6b28d5707bf01732980585b20b00dd`。启动时重新核对 EXE，版本不符拒绝启动。
- 本轮链路分析为 `reverse_lab/v3/reports/live-tests/skill-chain-analysis/`，每技能 JSON 保留具体采集窗口、构造范围、创建参数、实际绘制及代码调用证据。生成结果保存关联源文件、样本、构造序号与绘制起止。
- 归一化 PVF 缓存由 `skill_lab_v3` 的同源缓存扩展而来；新增 MOB/ACT/PTL/ANI 均从同一个快照读取。每条成员保留原始 SHA256 和运行目录 record。ANI 保留有序字段、源偏移和未消费节点。
- 参考用户交接包的怪物渲染/死亡接口与 `monster_demo/include/dnf/shared_death.hpp`；不导入其另一版本的 VA、HP 编码或怪物绑定。
- 字段解释应用本地 `dnf-pvf-reference` 技能；不以官方样例中空的 ANI 文件证明二进制语义。

## 时间、锚点与推导

身体阶段独立于仍在存活的效果。某个动作结束后玩家可以移动，而世界中的爆炸/地面效果继续播放。持久 Buff 使用人物当前坐标，不依赖重新构造。

`actor` 锚点随本次施法的角色运动，`spawn` 固定到生成时角色运动结果，`cast` 固定到施法起点加校准后的位置。源 ANI 原点始终保留。崩山击用 `spawn` 加已确认的123偏移；运行样本已经包含角色运动的投影坐标不会再叠加一次位移。

原生 descriptor +0x4D 选择创建路径，+0x4C 决定相对入口是否加父坐标；此区别保留于原分析。这里使用解析后的源规则/实测参数构建新实体，不调用原生函数，也不将另一版本地址用于独立程序。

构造时间不作为开始播放的依据。对于没有闭合控制器的效果，生成器从与源引用图相符的实绘 ANI 实例读取 first/last draw；以开始附层或身体攻击帧对齐。本策略保留可见分支而不是还原完整状态机，记录 `controller_complete=false`。多个相同路径的构造实例不会合并成一个动画。

允许推导后仍保留五条源诊断：缺失 `BlastBloodEx/sub_dodge.ani`，及浴血之怒四条 frame=-1 的 ALS 事件。已存在的 sub_dodge1/2 通过它们自身的引用和实际调用接入，不将缺失路径偷偷改名。

## 后续接入

怪物实例维护 id/generation、事件去重集合、HP、当前状态/时钟和冻结姿态/粒子。将来攻击判定模块给出最终命中时，可替换 `collision()` 的几何接受阶段，并调用 `acceptedHit()`；伤害公式可替换演示扣血。死亡由 HP 归零明确触发，死亡后拒绝新命中。只读资源共享，某一实例死亡/重置不会清空其他实例资源缓存。

技能控制器完整恢复后，以源事件替换 `content/battle.json` 中的校准时间表；保持渲染、源框、怪物实例及反馈格式不变。当前只加载鬼剑士系角色/装备资源；其他大类角色需要新的 CHR、外观 profile 和身体路径适配，不能只改职业名称。
