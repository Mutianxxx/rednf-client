## 后续程序如何使用这些结果

1. 先核对本文件的 EXE/PVF 哈希。使用本版严格解码的原始脚本、原始 token/字节及来源，不套用其他版本地址。
2. 通用窗口依据 UI loader span、绑定实例、控件遍历和图像请求建立关联；生命周期、代次和关联不完整时显示缺项，不按时间邻近猜所有者。
3. 类型配置使用 `cbt_schema.py`、`evn_schema.py`、`spatial_schema.py` 的现有接口，具体字段及示例以各专题文档为准。STM/WDM 的 `schema_complete` 仅表示结构识别，`semantic_complete` 仍为 `False`。
4. 资源按机器证据中的完整物理成员、NPK 哈希、offset/length 和帧范围定位。重名、缺图、未知枚举、未知状态列保留诊断。
5. 只实现已经确认的行为。ACT 调度、文字、特殊控件、裁剪和 GPU 归属等未闭合项不能借通用 IMG 预览自动补全。
6. 独立演示器可复用解析、资源定位与已确认的布局/选帧规则；外部程序不直接执行游戏 VA。接入预览后仍需同实例、同状态、同帧与原客户端对照。
