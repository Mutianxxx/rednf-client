# 后续端口规划清单

这份清单供用户确定目标平台和保真范围后拆分实施。资料准备完成不代表下列运行系统全部实现。每项完成须附当前源哈希、派生产物、运行测试和未支持内容。

**全量审计已扩展本清单：**后续执行以[25 类系统契约](../research/system-contracts.json)、[逐项台账](../research/gap-ledger.jsonl)和[本轮结果](09-full-sample-audit.md)为入口。下表中的四职业／712 技能、原选定区域和早期 FIE／DS 缺口属于初次合并时的范围；全量数据和原生追踪的最新状态见新入口，不能再用下表限制后续内容。

| 阶段 | 已可复用 | 后续工作与完成依据 |
|---|---|---|
| 来源与工具 | 完整PVF、全PC文件哈希、NPK目录、解析器、原APK与分析代码 | 携带匹配的NPK/音乐；固定目标工具链与许可证；校验新样本版本 |
| 共同模型 | 原字节/有序token、四CHR、712技能、3222任务、区域依赖和地图解释 | 制定稳定schema，单位/引用/未知项显式化；ID迁移表与依赖闭包验收 |
| 原尺寸渲染 | IMG/ANI元数据、原始示例、黑块/颜色/图层问题结论 | 所有部件层序、镜像、旋转、混合、裁剪、插值、相机/视差；逐帧对照原版截图 |
| 地图/城镇 | TWN/DGN/MAP/TIL与全部候选、门/选关图、天空边界修复依据 | 全城镇路由、NPC站位/交互、动态景物、机关/可破坏物、任务房间；全部候选出口可达 |

| 战斗与AI | PC源参数、Android调用链、GBA有限AI | PC公式、整数截断、状态/属性、命中停顿、浮空连击、怪物全部动作条件与首领策略；原PC行为样本 |

优先补证据的未知项：PC服务端伤害/奖励/持久化语义；各技能与怪物控制器；完整UI与动态场景行为；Android FIE/DS及任务未知类型/文字编码；同版本未修改APK/native对照；正式内容开放范围。未知项保留raw和定位，不用“素材齐全”替代实现计划。
