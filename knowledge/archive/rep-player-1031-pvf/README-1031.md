# 1031 PVF 技能与特效预览

双击本目录的 `Start-1031.cmd`，或打开 `build/rep_pvf_preview.exe`。这是独立修改的 rep-player 项目，运行时读取 1031 的 `Script.pvf` 和 `ImagePacks2`，不需要 REP 录像，也不依赖 dnf-native-demo 程序。

默认资源位置是 `D:\dnf-rebuild\DNF1031客户端`。窗口打开后后台解析 PVF、计算完整 SHA256、建立来源索引和加载图像，底部显示进度；路径可以在窗口顶部调整。异常显示在右侧诊断与底部状态栏，并保存在本项目 `validation/runtime/` 的独立会话目录。

## 建议先看这些

1. 默认进入 **“十角色模板体验（推断 / 含回退）”**。先用第二个下拉框选择角色，再选技能。动作与技能资源来自1031对应角色的CHR、技能表和SKL，使用共享的释放、事件、附层、对象、返站与清理流程。右侧列出绑定策略和来源；名称含“回退”的条目使用该角色临时普攻，供检查共用流程，不能按此评价该技能的完整原版表现。
2. 开关“技能特效”“被动对象”“身体”，比较每一部分的实际画面。原始皮肤编号默认 0；完整装备、武器和时装层尚未接入，所以人物是基础身体贴图。
3. 开启“攻击/受击盒”。红色为当前 ANI 的攻击盒，蓝色为受击盒的 XYZ 投影。它们是来源几何，不是伤害结算结果。
4. 怪物下拉框可手动查看 Stay、Damage1、Damage2、Down、Sit。勾选“接触触发受击（测试）”会在几何首次相交时切到所选反应。魔法冰球还会按源onAttack/onAfterAttack生成爆炸、清原弹体，爆炸主体源倍率0.95。关闭开关看完整空放；此接触是测试策略，未恢复原版命中接受、反应选择、伤害和硬直。
5. 切换 **“来源技能流程（已接入四项）”** 可比较原来的十字斩、魔法旋风、冰魄剑、魔法冰球。它们仍采用原来的来源控制流程，未替换成模板。切换“全部配方 / 注册特效 / 职业动作”可看原注册组和CHR动作；“全部 PVF ANI”直接浏览资源。右上角轨道下拉框可单独显示ANI，缺失和不支持项明确诊断。
6. “扩展特效 slot 2/3”默认关闭。这两条是十字斩已登记资源；进阶分支的资格和调度尚未还原，开启后仅供检查资源。

空格暂停/播放，R 重播，左右键每次移动 16.7 ms；时间条可直接定位。方向、倍率、缩放可调整。“导出来源 / 反馈”会保存当前配方、ANI 哈希、帧事件、原始 IMG 引用、实际 IMG、NPK/PVF 容器及偏移、图像 SHA256 和诊断，便于反馈具体问题。

## 这版的边界

这是验证 **1031 PVF/NUT状态 → CHR/SKL/OBJ → ANI/ALS/ATK → IMG → rep-player GPU 渲染** 的独立demo。先完成跨角色模板预览，再由用户查看效果后逐角色做专用适配。模板中的名字/路径匹配、阶段选择和特效生成时刻属于明确推断；无法匹配、被动或源NotApplicable等条目保留技能身份和回退标记，不因有画面就算真实技能完成。四条来源可见释放流程也保留，环境为技能Lv1、EX0、攻速1000、无方向键。

以下仍待后续：逐角色技能控制器、完整Squirrel宿主、装备/武器、音效、精确混合、攻击接受与伤害、怪物反应选择/死亡、PVP UI及“菜单”“商城”字体。ALS add/remove与普通附层已运行；none-effect特殊flag、随机/option命令、循环事件和完整原生时钟仍有缺口。DODGE是可切换加法近似；运动profile保留原数值，native精确取整待对照。自动检查不代表原版画面一致性通过。

本版尚未迁移到 dnf-native-demo。先由用户查看独立 demo，再决定采用哪些调用链和实现。

“注册特效检查”来自当前 `common.nut` 明确的技能 ID 分支和动画注册调用。其资源按调用顺序登记，同时起播仅是本工具的检查策略；通过轨道下拉框可逐个看。当前仅 Swordman 与 DemonicSwordman 在此文件有这些明确 loader；其他职业不会因此被判定为没有技能特效，需要继续分析其余脚本及原生消费者。

## 构建与恢复

执行 `powershell -ExecutionPolicy Bypass -File .\build-preview.ps1`。编译器可用 `-CompilerPath` 指定；默认查找本机 D 盘的 LLVM MinGW。项目自带 zlib 1.3.1 源码、静态库和来源清单，预览不依赖主项目游戏代码或 SDL。

自动检查入口是 `build/rep_pvf_preview.exe --verify D:\dnf-rebuild\rep-player-1031-pvf\validation\preview`。从 PowerShell 执行 GUI 子系统程序时，请用 `Start-Process -Wait -PassThru` 等待完成并读取 ExitCode；报告按次保存在独立目录。

当前进度及恢复入口见 `docs/PROGRESS.md` 和 `CURRENT_TASK.md`。已完成节点以 `tools/checkpoint-preview.ps1` 备份到相邻的 `rep-player-1031-pvf-checkpoints` 目录，包含完整源码、EXE、构建和验证记录及逐文件 SHA256。
