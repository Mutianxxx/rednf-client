## 变量名前缀速查（会话 9 全库语义化，详见 docs/26）

| 看到 | 意思 |
|---|---|
| `pArg1 / pszArg1 / uArg1 / pFn1` | 指针/字符串/无符号数/函数指针 参数 |
| `pFile / pMem / pBuf / psz / pObj` | 按**用法证据**命名：文件/堆内存/缓冲区/字符串/虚表宿主 |
| `pThis_4 / pThis_158` | 指向 this+0x4 / this+0x158 的指针（HEX 偏移） |
| `fld_158 / fld_e1` | 读出的字段值：字节偏移 0x158 / 元素下标 this[1] |
| `pNext / i / j / k` | 链表自追踪 / for 循环下标 |
| `v5`（没改名的） | 无证据保留原名——铁律"命名有据"，不编造 |
| 行尾 `// 【语义名】` | 该 sub_XXXX 调用对应的已定案语义（2,908 处） |
