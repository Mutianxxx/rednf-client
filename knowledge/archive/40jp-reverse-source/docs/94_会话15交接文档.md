## 四、如果要继续精修（虽然价值递减）

**纪律**（照抄，见 docs/60 + docs/99 §3.6）：

1. **只加注释/只改标识符，绝不改代码**（结构完整性是唯一底线）
2. **禁止写废话**：`// 返回 result`、`// 判定 x != 0`、`// 置 v18 = 0`、`// pThis = this`
   —— 一律不写（会话 12 已清洗 2.7 万条，别再造）
3. **无据跳过**（宁缺勿滥）
4. **脚本批量**（收集 `(old,new)` 一次性替换，不要一行一个 Edit）
5. **落盘前三守卫**：裸注释（`| +0x` 在 `//` 前）/ 骨架校验 / `^// 0x` 计数不变
6. **同一文件绝不并发写**（会话 12 实测事故）
7. **禁用 grep 做行首扫描**（本机是 ugrep，`^// ` 静默失配 → 用 Python）
8. **每批后必跑** `python tools/verify_refine.py` → PASS；FAIL 则 `tools/rollback_funcs.py <文件> <VA...>`

**派工模板**：`python tools/gen_func_cards.py --clean` → `--batch <文件> 0 <数量> <输出>` → 派 1 个代理
（**一次一个文件**，不并发同文件）。

**可精修空间**（`gen_func_cards.py --stats` 显示）：

```bash
python tools/gen_func_cards.py --stats   # 当前应显示"无头注释需处理: 0"
```

> 注：`gen_func_cards.py` 判定的是「函数头注释」缺失量（已 0）。行尾注释的剩余空间
> 见 `reproduce.py --verify` 打印的覆盖率（76.3% 有意义行）。
