# 来源与证据边界

本文件用于协作时避免把不同版本资料和工程推断混成客户端事实。更完整的 PVF 规则由用户本地离线知识库维护；该资料库不随共享交付包发布。

| 证据类 | 可以证明 | 不能单独证明 |
|---|---|---|
| 当前 1031 PVF/NPK 字节 | 路径、原始字段、帧/图片/碰撞数据、注册关系、压缩资源身份 | 运行时一定消费；未观察到的宿主调用、完整数值公式或资格 |
| 当前 C++ 实际消费者 | 当前工程怎么解释并执行一个来源字段 | 当前官方客户端也完全相同 |
| 40JP 逆向源码/二进制 | 2006 日服早期版本的引擎、动画、战斗调用结构线索 | 1031 的逐技能映射、数值、状态编号和原生资源绑定 |
| rednf / 安卓 / 60US / REP | 各自版本的实现或记录，可作为提出假设的证据 | 自动等价于当前 PC 1031 |
| 本项目策略/测试预览 | 工程为缺失机制提供的可撤回兼容行为 | 原版恢复或所有技能完整接入 |

## 当前已知边界

- 40JP 资料源版本标为 `200606130k0515`。它是通用结构参考，实际融合时应按函数体和调用者核实，不能只按逆向项目的注释或文件名照抄。
- 当前 1031 的代表 Fighter `SKL` 提供技能数值/学习/命令等数据，但不直接形成完整的 `SKL -> ANI -> ATK/PO/NUT` 调用图。当前 PVF 未发现 Fighter 专属 NUT 子树。
- 当前 Fighter 覆盖表是来源/适配状态账本。`nativeRecovered` 也只代表控制器家族结构有来源依据，不代表完整技能、视觉、伤害和动态体验已完成。
- 特效路径相同、NPK 文件名相似或资源存在均不是播放时机、局部坐标、判定框或生成条件的证据。
- ANI/ALS 时间、父子时钟、坐标空间、IMG 裁剪原点、局部附着和独立世界实体要分开处理。渲染采样不得推进模拟或重复触发事件。
- 完整自动测试、隐藏窗口检查、前台体验和原版动态对照是不同验收项。报告必须分别写明。

## 40JP 研究材料

当前融合依据和未闭合项摘要见 `reference-40jp/`。本共享包**不包含**原始 40JP 逆向源工程、`ARAD.exe`、原客户端、PVF/NPK、REP 文件或用户资料。已有文档中的源文件名/函数名只用于定位授权研究材料；协作者没有该材料时应按“结构参考”阅读，不得虚构源代码内容。

## 新证据记录

每项引擎/资源行为至少记录：目标客户端和版本/哈希、源文件路径与字段/偏移、消费者/调用者、解释过程、验证命令、未验证边界。跨版本适配另写：源版本、目标版本、映射依据、冲突处理、策略 ID、用户可复现步骤。任何未闭合调用链保留具体诊断。
