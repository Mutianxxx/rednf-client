# 平台与来源保全

当前实现为 Windows C++17/SDL2，未来 PSP/其他平台的数据需求继续保留。

- 游戏源码、资源服务和平台表现按职责分目录；当前尚未宣称完全清除核心的 Windows 依赖。
- 客户端/PVF 是内容来源；安卓、60US、REP/社区样例保留各自版本与证据层级。
- 保留原字段顺序、重复/未知标签、源坐标/时间/字节和身份，不将平台适配写回原数据。
- 两个 ANI 原生合同已置于 `third_party/native-contracts/include`，保留来源哈希；不是重新猜测格式。
- 补充资料和历史实现/验证成果见 `../../knowledge/INDEX.md`。禁止导入旧GBA实现/派生资源或DFQ UI。
- 工具链是外置、可配置的只读开发依赖；运行产物只依赖源客户端资源及随包 DLL。
- 新工程/候选使用私有存档，不复制原用户角色；存档格式和正常/测试隔离合同保持。

完整持久化接口、平台设备接口和构建库依赖分层属于后续迁移。目录分组不等于已完成跨平台移植。
