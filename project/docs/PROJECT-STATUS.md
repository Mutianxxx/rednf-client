# 工程当前状态

状态基准：2026-11-03。本文仅说明本次 C++ 独立工程实际范围；自动测试数量、资源索引数、注册数和候选文件数均不作为游戏完成度。

## 已落地

- 从已验证源码基线独立迁入，源码按 `app/content/diagnostics/persistence/presentation/render/resources/simulation/tools` 分组。
- `GameApplication` 管理单次运行路径；`CharacterPresentation` 与同步 draw sink 分离人物层组合；`FrameStatistics` 使用有界采样。
- PVF/NPK 访问、内容身份、来源字段保留、多个公共战斗/受击/怪物/地图/UI消费者已存在。
- 40JP 的部分动画时序、递归附层、攻击/受击结构已迁入公共消费者；当前 40JP Fighter 体验线包含来源调用点驱动的特效 cue、局部变换及目标缩放。
- 活跃源码唯一所有权清单与 `tools/verify_architecture.py` 检查已建立。

## 未完成 / 不能对外宣称

- 当前不是完整 DNF 客户端替代品，也不是最终 beta；没有所有十职业技能、转职/觉醒、NUT、怪物 AI、UI 或所有副本机制完整支持的证据。
- 女格斗技能链仍有大量跨版本推断、未支持被动和未知项。用户上一轮反馈动作/音效改善，但技能仍存在错配；最新 build-only 候选尚待再次前台确认。
- 1031 当前资源不直接给出代表技能的完整 `SKL -> ANI -> ATK/PO/NUT` 运行调用图；40JP 不可单独填补目标版本映射。
- `World` 的部分公开可写状态、`Renderer` 的高层责任、`dnf_core` 单一链接归档和 UI 命令/只读模型仍待重构。
- 当前构建/定向检查通过不代表完整回归、画面、音效、手感或原版动态对照通过。性能也没有统一同机基线和固定提升承诺。
