## 已落地的代码变化

| 对象/模块 | 实际消费者 | 所有权与边界 |
|---|---|---|
| `app::GameApplication` | `src/app/main.cpp` 创建并执行 | 拥有本次运行路径和诊断身份，替代原文件级可写全局状态；保留既有 World/设备局部生命周期 |
| `CharacterPresentation` | `Renderer::player()` 委托 | 只读 Actor/Appearance；组合身体、装备、时装和技能前后附属层；不改时钟/血量/实体 |
| `ICharacterDrawSink` | Renderer 私有实现 | 同步动画请求及诊断接口；不向表现对象暴露 SDL/纹理或可写 World |
| `diagnostics::FrameStatistics` | 主循环逐帧记录、退出时生成报告 | 固定容量连续环形缓冲；记录时不排序/分配；全程计数/峰值与最近窗口分位分开 |
| 源码职责目录 | CMake 真实编译输入 | 125 个原实现单元迁入模块目录；新增对象经 `source-ownership.json` 登记和检查 |

身体、装备和时装仍按原 EQU 顺序交织，不能改成三批绘制。继续保持各自 ANI 时钟、
ALS/技能附件生命周期、原点/局部/世界坐标、朝向和失败提示的像素偏移。
当前外观字段仍有旧公开接口，因此没有擅自添加按地址缓存或改变帧采样。
