# 本轮重构体验检查

本轮目标是保持已验证 457 的现有功能与表现，不把历史未完成功能计为新增完成。
自动结果见构建收据；以下前台画面、声音和操作由用户确认。

1. 通过 `Play.cmd` 或 `Run-From-Source.cmd` 启动；创建独立测试角色。
   当前脚本不读取旧用户存档，检查点也使用自己的 `runtime/saves/`。
2. 检查站立、走跑、跳跃、普攻和已可用技能：身体、武器、时装遮挡顺序及技能前后特效
   是否与旧 457 一致，是否出现新的卡帧、脚下错位、镜像或服装消失。
3. 换装备、换装扮及切换角色，确认普通无外观防具不会清空时装；关注女枪重武器层。
4. 打开背包/技能窗口，和 NPC 对话/商店交互；进入原来可玩的地图，检查地图视差、门、
   怪物装备、受击/死亡效果、音效和掉落有无相较旧版本的新增退步。
5. 使用常用分辨率与同一场景比较操作和帧时间。当前统计把全程峰值/计数与最近4096帧
   分位分开；不能把短窗口P95与旧整场P95直接比较。

如有问题，记录：使用的启动脚本完整路径、角色/职业、装备/装扮、地图、动作/技能、
分辨率、是否可重复，以及同场景旧457是否也存在。可按原有 F8/F12 收集反馈/截图；
日志位于运行目录或脚本指定的 reports 下。原版动态一致性仍单独记录。
