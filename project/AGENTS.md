# C++ 重构源码规则

开始前读 `CURRENT_TASK.md`、`MIGRATION.md`、`docs/IMPLEMENTATION.md`、`docs/RENDERING.md`、`docs/PORTING.md`。
工作区整体状态在 `../PROGRESS.md`；如果从节点恢复，先读节点根 `PROGRESS.md`、`manifest.json` 与实际验证收据。

- 当前可执行基线为 457 的独立迁入，不把旧459堆异常或全部技能缺口标为已修复。
- 按职责和状态所有权做面向对象重构，组合优先。公共动作/动画/战斗复用，职业差异集中注册；禁止逐技能复制。
- 新源单元必须登记 `cmake/source-ownership.json` 并接入真实运行消费者；空类和未调用算法不算完成。
- UI/渲染读状态；状态修改逐步收敛到所属对象/服务和有序命令，不新增任意 World 写入口。
- 保留原始时间、坐标、字段、来源身份和未知项。原始客户端/PVF优先，跨版本资料/推理单独分类。
- 资料入口为 `../knowledge/INDEX.md` 与其中的知识规则。旧GBA实现/派生资源和DFQ UI禁止导入。
- 原工程、原始资料、历史候选和用户存档保持只读；所有输出、缓存、测试和私有存档留在本目录。
- 构建/运行/打包串行，不改正在验证的输入，不杀未知进程或删除他人锁。
- 每个实质节点运行对应检查，保存源码/产物/报告和两遍哈希备份。自动验证、前台体验和原版动态比较分别记录。
