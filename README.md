# DNF 1031 客户端行为复刻工程

一个独立的 C++17 工程，用**数据驱动**的方式复刻《地下城与勇士》（Dungeon & Fighter）1031 版本客户端的
单机游玩行为：角色与技能动作、战斗判定、怪物行为、掉落与成长、存档恢复。工程只包含代码与测试，
**不包含**任何客户端资源（`.pvf`、`.npk`、贴图、音频、可执行文件）。

> 运行需要你自行提供合法拥有的 1031 客户端数据目录。仓库内不附带、也不分发游戏素材。

---

## 这是什么

原生 C++ 实现的单机客户端：读取客户端数据包中的角色、技能、动画、攻击信息与地图定义，
在本地渲染并驱动一套完整的战斗循环。目标是把「技能怎么动、打到哪里、什么时候打中、打完怎么结算」
表达成可读、可测、可复现的代码，而不是靠记忆或主观调参。

当前可完成的一局流程：

- 创建角色 → 城镇移动 → 进入副本 → 清理房间 → 击杀与掉落 → 拾取 → 通关结算 → 返回城镇
- 角色升级、经验、金币、装备属性、技能学习与快捷栏释放
- 主动技能的身体动作、特效层、投射物/被动对象、命中与受击反应
- 死亡、掉落、奖励与存档的持久化，支持异常退出后的恢复

## 当前状态

工程**仍在完善中**，且已暂停更新（见文末）。可玩的部分：

| 能力 | 状态 |
| --- | --- |
| 城镇/副本移动、房间切换、门与传送 | 可用 |
| 普攻、跳跃攻击、技能释放与连段 | 可用，覆盖随职业推进 |
| 伤害、命中判定、受击硬直、浮空倒地、命中停顿 | 可用 |
| 怪物巡逻/追击/攻击、死亡表现与尸体清理 | 可用 |
| 掉落、拾取、金币、经验、升级 | 可用 |
| 存档、奖励事务、崩溃恢复 | 可用 |
| 技能学习、SP 消耗、快捷栏 | 可用，按职业逐步接入 |
| 全部职业的全部技能 | **未完成** |

未完成与已知限制：

- **技能覆盖不完整**：部分职业只有基础动作，部分技能仅有动作与特效、尚无完整伤害与状态消费。
- 职业间的行为覆盖不均衡，个别职业仍缺少专用执行器。
- 少量参数属于工程内重建值（数据文件中没有对应字段），代码中以 `reconstructed` 标注。
- 与官方客户端的手感、帧时序、打击反馈未做逐帧一致性验证。

## 构建

需要 CMake 3.20+、Ninja 与 Python 3（构建脚本使用标准库）。编译器使用工程内约定的工具链配置。

```bash
cd project
python -X utf8 -B tools/build.py --build-dir ../checkpoints/build --test-dir ../checkpoints/tests
```

产物写入 `checkpoints/build`，测试输出写入 `checkpoints/tests`，两者均在仓库内且已被忽略。

## 运行

1. 准备 1031 客户端数据目录，确认 `project/content-profile.json` 与 `project/toolchain.local.json`
   指向它（这两个文件是本机配置，不随仓库分发）。
2. 启动：

```
project/Play.cmd
```

技能预览器用于逐个查看动作与特效：

```
project/Play-Skill-Preview.cmd
```

## 测试

```bash
checkpoints/build/dnf_tests.exe <客户端数据目录> --group 1
checkpoints/build/dnf_tests.exe <客户端数据目录> --focus <套件名>
```

测试分为模拟与存档、战斗与技能、内容与渲染等分组。部分用例依赖真实客户端数据，
缺少数据目录时会跳过或失败。
